# 개인정보처리방침

**잇다-** (이하 "팀")은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 준수합니다.
본 개인정보처리방침은 서비스 **팀 잇다** (https://ittda.vercel.app/) 에 적용됩니다.

> **시행일**: 2026년 3월 18일

---

## 1. 수집하는 개인정보 항목 및 수집 방법

### 1.1 소셜 로그인을 통한 수집

이용자가 Google 또는 Kakao 계정으로 로그인할 때 아래 정보를 수집합니다.

| 항목 | 필수/선택 | 수집 출처 |
|------|----------|----------|
| OAuth 공급자 고유 ID | 필수 | Google / Kakao |
| 닉네임(표시명) | 필수 | Google / Kakao |
| 이메일 주소 | 선택 | Google / Kakao (Kakao는 사용자 동의 시에만) |
| 프로필 이미지 | 선택 | Google / Kakao |

### 1.2 서비스 이용 과정에서 수집

| 항목 | 수집 시점 |
|------|----------|
| 기록 제목 및 내용 | 기록 작성 시 |
| 사진 및 영상 파일 | 미디어 업로드 시 |
| 사진 EXIF 메타데이터 (위치정보, 촬영 일시 등) | 사진 업로드 시 자동 추출 |
| 위치 정보 (위도/경도) | 기록에 위치 첨부 시 |
| 감정 태그, 평점, 텍스트 태그 | 기록 작성 시 |
| 그룹 내 닉네임 및 프로필 이미지 | 그룹 설정 변경 시 |

### 1.3 서비스 이용 시 자동 수집

| 항목 | 설명 |
|------|------|
| 쿠키 (Cookie) | 로그인 상태 유지(JWT 토큰), 세션 관리 |
| 접속 IP 주소 | 서버 보안 및 오류 대응 |
| 접속 일시 | 서비스 안정성 분석 |
| 기기 정보 | 모바일 앱 이용 시 (OS 종류 등) |

### 1.4 비회원(게스트) 이용

회원 가입 없이 게스트로 서비스를 이용하는 경우, 개인 식별 정보 없이 임시 세션 ID만 발급됩니다. 게스트 세션은 일정 기간 후 만료됩니다.

---

## 2. 개인정보의 수집 및 이용 목적

팀은 수집한 개인정보를 다음 목적으로만 이용합니다.

1. **회원 식별 및 인증**: 로그인, 로그아웃, 계정 관리
2. **서비스 제공**: 기록 작성·편집·조회, 실시간 공동 편집, 그룹 관리
3. **위치 기반 기능**: 기록에 첨부된 위치 정보를 지도에 시각화
4. **사진 메타데이터 자동 입력**: 업로드한 사진의 EXIF 정보를 기록 필드에 자동 반영
5. **서비스 개선 및 오류 대응**: 접속 로그 분석, 장애 대응

---

## 3. 개인정보의 보유 및 이용 기간

| 구분 | 보유 기간 |
|------|----------|
| 회원 정보 | 회원 탈퇴 요청 시까지 |
| 기록 및 미디어 | 이용자 삭제 요청 또는 회원 탈퇴 시까지 |
| 리프레시 토큰 | 발급일로부터 **14일** |
| 게스트 세션 | 세션 만료 시까지 (수일 이내) |

회원 탈퇴 시 개인정보는 지체 없이 삭제되며, 관계 법령에서 보존 의무를 정한 경우 해당 기간 동안 별도 보관 후 삭제합니다.

---

## 4. 개인정보의 제3자 제공

팀은 이용자의 동의 없이 개인정보를 외부에 제공하지 않습니다.
단, 아래의 경우는 예외입니다.

- 이용자가 사전에 동의한 경우
- 법령에 따른 수사기관의 적법한 요청이 있는 경우

## 5. 개인정보 처리 위탁

서비스 운영을 위해 아래 업체에 일부 업무를 위탁합니다.

| 수탁업체 | 위탁 업무 | 보유 기간 |
|---------|---------|----------|
| 네이버 클라우드 플랫폼 | 사진 및 미디어 파일 저장·관리 | 위탁 계약 기간 |
| Google | OAuth 인증 서비스 | 인증 처리 후 즉시 |
| Kakao | OAuth 인증 서비스 | 인증 처리 후 즉시 |

위탁 업체는 개인정보를 위탁 목적 범위 내에서만 처리하며, 각사의 개인정보처리방침을 따릅니다.

## 6. 이용자의 권리 및 행사 방법

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

- **열람**: 수집·이용 중인 개인정보 확인
- **정정**: 부정확한 정보 수정 요청
- **삭제**: 개인정보 삭제 요청 (회원 탈퇴 포함)
- **처리 정지**: 특정 목적의 개인정보 처리 중단 요청

권리 행사는 아래 연락처로 요청해 주세요. 요청 후 **10일 이내** 처리합니다.
만 14세 미만 아동의 경우 법정 대리인이 권리를 행사해야 합니다.

## 7. 개인정보의 안전성 확보 조치

| 조치 | 내용 |
|------|------|
| 암호화 통신 | HTTPS를 통한 전송 구간 암호화 |

## 8. 쿠키(Cookie) 정책

서비스는 로그인 상태 유지를 위해 쿠키를 사용합니다.

- **사용 쿠키**: JWT 액세스 토큰, 리프레시 토큰
- **저장 방식**: HttpOnly 쿠키 (JavaScript로 접근 불가)
- **만료**: 액세스 토큰 15분, 리프레시 토큰 14일

브라우저 설정에서 쿠키를 거부할 수 있으나, 이 경우 로그인이 필요한 기능을 이용할 수 없습니다.
